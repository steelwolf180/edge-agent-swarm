## Decision
Proceed with local-only architecture despite spec suggesting cloud integration points
## Consequences
System will be deployed on a single edge machine with local execution only, assuming zero cloud costs. This aligns with the spec's requirement for local-only deployment and avoids cloud expenditure. The architecture will rely on local infrastructure (Docker, PostgreSQL) and internal components (LLAMA Server, Researcher/Architect outputs).
