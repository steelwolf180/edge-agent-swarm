## Context
L1 System Context
## Decision
Implement a local application that processes Markdown notes using Python and interacts with an external LLM via hosted APIs for ingestion and generation, while maintaining all data locally.
## Consequences
The system will be pay-per-use for external API interactions, with costs based on text processing volume and LLM token usage. Local data storage remains secure and private, with no cloud infrastructure required.
