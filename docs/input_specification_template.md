# Architecture Specification

## 1. Project Overview

- Purpose / problem being solved
- Target users
- Deployment environment (cloud/on-prem/edge/hybrid)

## 2. Functional Requirements

- Core features
- Key user flows
- Integration points (external APIs, third-party services)

## 3. Non-Functional Requirements

- Performance (latency, throughput targets)
- Scalability (expected load, growth projections)
- Availability (uptime SLA, failover expectations)
- Security (auth model, data sensitivity, compliance)
- Observability (logging, monitoring, alerting needs)

# 4. Technical Constraints

- Language/framework mandates
- Existing systems to integrate with
- Budget or infrastructure limits
- Team skill set constraints

## 5. Data Architecture

- Data sources and types
- Storage requirements
- Data flow and transformation needs
- Retention and compliance requirements

## 6. Open Questions

- Known unknowns the architect flagged upfront
